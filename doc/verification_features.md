# 검증 결과 안내 기능 추가

## 변경
- 서버에서 검증 전 AnswerToken 전송을 차단하고 화면에서도 해당 이벤트를 무시한다. 진행 단계는 계속 표시한다.
- 최종 응답에 시스템·항목·수집값·답변값·판정 비교표를 붙인다. 실패 시 마지막 반려 초안에 대한 표임을 안내한다.
- 수치 추출 누락 가능성과 원인·상태·권장 조치 미검증 범위를 명시한다. 추출 수치가 없으면 수치 검증 완료가 아님을 안내한다.
- 모니터링 자료가 없으면 최초 검증에서 자료 부족으로 종료한다. 재작성으로 자료를 보충할 수 없기 때문이다.

## 검증
- 기존 평가셋: 정상 7/8 통과, 오류 9/9 차단 유지.
- 비교표 일치/불일치, 수치 미추출, 통과/재작성/3회 실패/자료 부족 네 경로 확인.
- 실제 서버 스트림 함수에 모의 그래프를 연결하여 초안 비공개·최종 보고서 전달 확인.
- 실제 HTML에 모의 실패 이벤트를 주입: 반려 초안 미노출, 실패 안내·비교표·검증 범위 표시, JavaScript 오류 0건.
- 실제 로컬 HTTP 서버 + fake 모델 + MCP 실행: 초안 토큰 미전송, 최종 검사 통과, 비교 행 2개 전달 확인.
- 실모델(Ollama/OpenAI)은 이번 변경 후 재실행하지 않음.

## 남은 한계
표현·표·부정문 등에 대한 검증기의 누락과 오탐은 그대로다. 비교표는 추출된 수치의 대조 결과이며 답변 전체의 진실성을 보장하지 않는다. v1/legacy 비교 모드는 근거 검증 완료라고 표시하지 않는다.
